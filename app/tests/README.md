# Регрессионные проверки

Быстрый прогон unit-тестов в контейнере:

```bash
docker compose exec -T bot python -m unittest discover -s tests -v
```

Проверки покрывают:

- короткие ставки (`200` → `200000`, `80 ндс` → `80000`);
- явные единицы (`р/км`);
- исключение дат, веса и `20/82` из ставок;
- нормализацию городов и сокращений;
- базовые расчёты НДС и маржи;
- идемпотентные ключи webhook.

Дополнительно полезно периодически проверять живой DeepSeek/DaData разбор, потому что unit-тесты не гарантируют ответы внешних API.
